## Overview

InsightEdu helps teachers see how engaged a class is while it happens. It was a team effort, and I was part of it from the first idea to launch, working across a React, TypeScript and Tailwind frontend on Firebase, MediaPipe for activity monitoring, and an Express API behind it.
