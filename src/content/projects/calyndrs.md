## Overview

Calyndrs brings everything around an event into one place: organizers set it up, promote it and track how it performs, venues and event companies plug into the same workflows, and attendees discover and book. I've worked on it part-time as a full-stack engineer since April 2026. It runs on a Next.js frontend and a Nest.js API on MongoDB, deployed on AWS.
