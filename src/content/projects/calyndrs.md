## Overview

Calyndrs brings everything around an event into one place: organizers set it up, promote it and track how it performs, venues and event companies plug into the same workflows, and attendees discover and book. I co-founded Calyndrs in 2026 and I'm building it as a product, with a Next.js frontend and a Nest.js API on MongoDB.
