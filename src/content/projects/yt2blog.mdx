## Overview

A tutorial video already holds an article, but a transcript isn't one. yt2blog takes a YouTube URL and writes a restructured explainer: an intro, sections in reading order with links to the right moment in the video, code blocks, takeaways, a short FAQ, SEO metadata and `VideoObject` and `FAQPage` JSON-LD. The video is embedded as a companion, not the main content.

It's for anyone who publishes tutorials on YouTube and wants a written version of each one on their blog without writing it from scratch. It's a solo project and open source.

## How it works

Run `yt2blog` and it asks for the keys, the video and the destination one step at a time, then shows the stages as a live checklist. The finished article is always saved as Markdown. It can also go to Ghost or Sanity as a draft, so a person reviews it and decides when to publish.

The model never writes the code readers will copy. When the video links a GitHub repo, it only picks where each block lives, and the tool cuts those lines from the real file. Anything it can't match is flagged for review.
